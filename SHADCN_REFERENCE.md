# Tham chiếu giao diện shadcn.io

Prototype không sao chép source code block Pro. Nó dùng lại **pattern bố cục** phù hợp với developer tool:

1. **React App Shell Skeleton** — navbar + sidebar + vùng nội dung chính + aside.
   - https://www.shadcn.io/blocks/skeleton-app-shell
2. **Sidebar With Command Menu** — command/search trigger kiểu developer tool.
   - https://www.shadcn.io/blocks/sidebar-with-command-menu
3. **Resizable** — split panels cho file tree, editor, console và inspector.
   - https://www.shadcn.io/ui/resizable
4. **Design Tool Sidebar** — cách tổ chức tool rail và các nhóm công cụ.
   - https://www.shadcn.io/blocks/sidebar-design-tool

Leanbot Studio biến các pattern trên thành IDE layout riêng, không dùng dashboard cards theo kiểu quản trị doanh nghiệp.
